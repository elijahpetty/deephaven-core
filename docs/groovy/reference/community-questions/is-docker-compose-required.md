---
title: Is Docker Compose required?
---

<em>Many examples in your installation guides show the use of `docker compose`. Is it required?</em>

<p></p>

No. You can run Deephaven via Docker without [Docker Compose](https://docs.docker.com/compose/). See [the simplest possible installation](../../getting-started/docker-install.md#the-simplest-possible-installation) for an example that uses only `docker run`. Docker Compose does make customizing your deployment easier, though, so we recommend it for users who want to do that.
